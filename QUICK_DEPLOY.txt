## 1️⃣ CREATE GITHUB REPO

Go to: https://github.com/new

**Settings:**
- Name: `Soward-Bot`
- Visibility: **Public**
- Create repository

## 2️⃣ PUSH TO GITHUB

Copy these commands and paste in PowerShell. Replace `YOUR_USERNAME` with your GitHub username:

```powershell
cd c:\Users\HP\Downloads\Soward-Bot-main
& "C:\Program Files\Git\bin\git.exe" branch -M main
& "C:\Program Files\Git\bin\git.exe" remote add origin https://github.com/YOUR_USERNAME/Soward-Bot.git
& "C:\Program Files\Git\bin\git.exe" push -u origin main
```

Then enter your GitHub credentials when prompted.

---

## 3️⃣ DEPLOY ON RAILWAY

1. Go to: https://railway.app
2. Sign up with **GitHub** (free, takes 1 minute)
3. Click **"New Project"**
4. Select **"Deploy from GitHub"**
5. Choose **Soward-Bot** repo
6. **Railway auto-builds & deploys!** ✨

---

## 4️⃣ SET VARIABLES IN RAILWAY

In Railway Dashboard → Your Project → **Variables** tab:

**Add these (copy exact names):**

| Variable | Value |
|----------|-------|
| `TOKEN` | Your Discord bot token |
| `API_PORT` | `3000` |
| `LOG_LEVEL` | `INFO` |

---

## 5️⃣ ENABLE DISCORD INTENTS (CRITICAL!)

**This must be done or bot won't connect!**

1. Go to: https://discord.com/developers/applications
2. Select your bot
3. Go to **"Bot"** section
4. Enable these **Privileged Intents:**
   - ✓ MESSAGE_CONTENT
   - ✓ GUILD_MEMBERS
   - ✓ GUILD_PRESENCES
5. **Save**
6. Go back to Railway → Click **Redeploy**

---

## 6️⃣ GET YOUR DASHBOARD LINK

After ~5 minutes (deployment completes):

1. Railway Dashboard → Your Project
2. Go to **Deployments** tab
3. Click active deployment
4. Copy **Public URL**

**Your 24/7 Dashboard:**
```
https://your-url.up.railway.app
```

Share this link! It's live forever. 🎉
