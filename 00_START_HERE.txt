STEP 2: Push Code to GitHub
  → Replace YOUR_USERNAME in each line
  → Copy-paste these commands:

  cd c:\Users\HP\Downloads\Soward-Bot-main
  & "C:\Program Files\Git\bin\git.exe" branch -M main
  & "C:\Program Files\Git\bin\git.exe" remote add origin https://github.com/YOUR_USERNAME/Soward-Bot.git
  & "C:\Program Files\Git\bin\git.exe" push -u origin main

  → Enter your GitHub password when prompted
  → Takes 30-60 seconds

STEP 3: Deploy on Railway
  1. Go to: https://railway.app
  2. Sign up with GitHub (free)
  3. Click: "New Project"
  4. Select: "Deploy from GitHub"
  5. Choose: Soward-Bot repo
  → Railway auto-builds & deploys (takes 2-5 minutes)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 4: Configure Variables in Railway
  → Go to: Your Project → Variables tab
  → Add these (copy exact names and values):

    TOKEN = your_discord_bot_token
    API_PORT = 3000
    LOG_LEVEL = INFO

  → Save variables

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 5: Enable Discord Intents (CRITICAL!)
  ⚠️  Bot won't work without this!

  1. Go to: https://discord.com/developers/applications
  2. Select: Your bot application
  3. Go to: "Bot" section (left sidebar)
  4. Enable these Privileged Intents:
     ✓ MESSAGE_CONTENT
     ✓ GUILD_MEMBERS
     ✓ GUILD_PRESENCES
  5. Click: Save Changes
  6. Go back to Railway & click: Redeploy

  → Wait for Railway deployment to finish (~5 minutes total)

  → Copy the "Public URL"

  Your 24/7 Dashboard:

🆘 TROUBLESHOOTING

❌ "Build failed" 
→ Check Railway Build Logs tab (usually dependency issue)

❌ "Bot won't connect to Discord"
→ Enable Privileged Intents (Step 5) and redeploy

❌ "Dashboard shows 502 error"
→ Wait 1-2 minutes for deployment to fully start, then refresh

❌ "Git push failed"
→ Make sure you replaced YOUR_USERNAME with your actual GitHub username

❌ "Can't create GitHub repo"
→ Make sure you're logged in to GitHub.com
